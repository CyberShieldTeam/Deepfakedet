# Video scope and trained-model decision

Current pipeline actually executes bounded OpenCV decoding, nearby quality-based selection (up to6JPEG frames), YuNet, optional whole-image/face-crop inference, adjacent-original Farneback measurements, supervised sparse temporal diagnostics and FFmpeg audio extraction/AASIST handoff. Browser sampling is separate and does not replace server original-video analysis. Original-video SHA, frame received/decoded/tensor hashes, extracted-WAV SHA, AASIST padded-window hashes, model states and timestamps remain separate.

Optical flow measures motion/residuals. Face tracking is geometric candidate continuity, not identity verification. Neither scene cuts, ordinary motion, face presence, a raw frame score nor a high audio score proves video manipulation. No new video-level pooling or multimodal confidence was introduced.

Primary code checked: [SBI video inference](https://github.com/mapooon/SelfBlendedImages/blob/master/src/inference/inference_video.py), [SBI Dockerfile](https://github.com/mapooon/SelfBlendedImages/blob/master/dockerfiles/Dockerfile), [FTCN config](https://github.com/SCLBD/DeepfakeBench/blob/main/training/config/detector/ftcn.yaml), [FTCN detector](https://github.com/SCLBD/DeepfakeBench/blob/main/training/detectors/ftcn_detector.py). Publisher scores were not substituted for local metrics. No assumption that any model covers whole-frame generation, face swaps, lip sync and recontextualization equally. Audio-visual consistency is not implemented or validated.

**Video-level detection accuracy/precision/recall/F1/AUROC/FPR/FNR/per-manipulation metrics: unavailable.** No rights-cleared identity-disjoint genuine/manipulated video corpus and compatible trained checkpoint were acquired. Dataset access/usage terms and a separate runtime are concrete remaining work; this is not a claim CPU execution is impossible. No large downloads authorized or performed for these models.

Actual browser software checks: existing test pattern without audio, with tone, scene cut, and a newly composed pattern with publisher-labelled genuine speech. The last is a **procedural composition**, not genuine camera capture or a labelled deepfake benchmark. Frames, absent/unavailable stages, audio track status and timestamps survived API→disk→graph→rendered report. Existing procedural video measurements remain history; they were not rebranded as an independent validation dataset.

Limits retained:8MiB original,120s/3600frames/1920×1080; at most6screened frames; existing FFmpeg/audio and temporal-worker deadlines. Sparse sampling can miss localized manipulation. JPEG frame extraction changes encoding; frame traces identify this transformed evidence, not original camera frames. Next: rights-cleared source/identity-grouped video data and one manipulation-specific detector with publisher-code parity in an isolated runtime, before any deployment or score pooling.

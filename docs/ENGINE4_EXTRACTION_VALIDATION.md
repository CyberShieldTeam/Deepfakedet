# Engine 4.1 validation

Baseline: `c4fe717`, `codex/integrate-figma-upgrade`, clean/synchronized before edits.
All runtime controls use authored images, temporary stores and fixture corpus documents;
no default case store, original model threshold or prior report was replaced.

## Repeatable setup

1. `npm ci`; install existing Python requirements in the project environment.
2. Explicitly run `python -m ai_service.download_ocr` once. It refuses an existing file,
   verifies publisher Git blob, 4,113,088 byte size and SHA-256, and saves only ignored
   `.model-cache/ocr/eng.traineddata`. No startup or upload triggers a download.
3. Start `python -m uvicorn ai_service.app:app --host 127.0.0.1 --port 8417` and set
   `VERITAS_AI_SERVICE_URL=http://127.0.0.1:8417` in the web process.
4. `python -m ai_service.create_extraction_fixtures` renders authored controls using local
   Windows Arial/Nirmala fonts. Rendering/shaping is not independent annotation.
5. `npm run test:extraction` and `npm run test:extraction:api` exercise actual local OCR,
   a temporary operator corpus, signed original media, owned routes and temporary cases.
6. `python -m ai_service.profile_extraction` writes a fresh resource report and refuses
   overwrite. For a repeat, preserve the old report under another name first.

## Future annotated-data interface

`python -m ai_service.evaluate_extraction manifest.json --output fresh-report.json` reads
at most 2 MiB/100 observations, fetches no media/URLs and refuses output overwrite.
Requires schemaVersion=1, independent=true, split=development and nonempty datasetId,
rights, permissionEvidence, annotationProtocol, annotationProvenance, approvedBy,
approvedAt. Rights/independence are operator declarations, not automatically proven.
Holdout/test input is locked pending a separately frozen evaluation release.

Optional sections are independent arrays, each row with id and original sourceSha256:
- ocr/speech: reference and prediction strings (≤500 characters), yielding separately
  micro-aggregated CER/WER; NFC, case/punctuation preserved, whitespace word splitting.
- candidates/relationships: unique exact anchored observation-ID sets in reference and
  prediction, yielding exact-match precision/recall/F1. Annotation protocol must define
  span/node identity before collecting predictions; no fuzzy semantic matching.
- reviewAgreement: two distinct reviewers plus first/second review states, yielding
  observed agreement (not chance-adjusted kappa).

Missing annotations yield null, never an invented score. Four math/admission tests pass;
these are software controls, not a dataset evaluation. No independent release was run.

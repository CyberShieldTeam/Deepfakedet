# AASIST audio engine record

Source: [NAVER Clova AI's official AASIST implementation](https://github.com/clovaai/aasist), MIT license. The network definition in `ai_service/vendor/aasist_model.py` is copied from commit `a04c9863f63d44471dde8a6abcb3b082b07cd1d1`; its license is in `ai_service/vendor/LICENSE.AASIST`. The official `models/weights/AASIST.pth` checkpoint from that commit has SHA-256 `51d2d9cf0738172f61e2a384ec50a54a55363240f67c971ed55a92435bc1a1c0`. It is downloaded into ignored `ai_service/models/` and loaded with PyTorch `weights_only=True` plus strict state-dictionary matching. No weights are committed.

Task: speech anti-spoofing, trained with ASVspoof 2019 Logical Access speech. The upstream evaluation uses the class-1 bona-fide logit; class 0 is spoof. This is not a general detector for music, ambient audio, or every voice-cloning technique. The [original paper](https://arxiv.org/abs/2110.01200) reports in-domain results. A [separate benchmark of the official checkpoint](https://huggingface.co/SpeechAntiSpoofingBenchmarks/AASIST) reports much weaker results on InTheWild speech. Neither source is a VERITAS accuracy measurement.

Preprocessing: inspect duration and format before decoding, decode with libsndfile, downmix channels, polyphase-resample to 16 kHz, split into non-overlapping 64,600-sample windows (4.0375 seconds), repeat-pad a final window of at least one second, and skip low-RMS windows. The RMS gate detects silence only; it does not establish that speech is present. Input is limited to 12 MB and 60 seconds. WAV, FLAC, OGG, and MP3 formats supported by the installed libsndfile can be decoded; M4A may not be supported. The browser currently sends media bytes only up to 7 MB to the server.

Output: each segment has start/end timestamps, a raw bona-fide logit, and a raw spoof-class softmax value. These are **uncalibrated** values, not a spoof probability or confidence. The service and UI always report `INCONCLUSIVE`; Gemini, when available, can return a separate verdict. No segment aggregation into an authenticity decision is implemented.

Local setup: install `ai_service/requirements.txt`, run `python -m ai_service.download_aasist`, set `VERITAS_AUDIO_MODEL_ENABLED=1`, start `uvicorn ai_service.app:app --host 127.0.0.1 --port 8001`, and point Express at it with `VERITAS_AI_SERVICE_URL=http://127.0.0.1:8001`. The `/health` response reports the audio engine separately. `npm run smoke:audio:http` exercises an audio fixture through Express and Python; the fixture has no verified authenticity label and is only a transport and inference check.

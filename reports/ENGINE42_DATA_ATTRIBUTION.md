Yasuhisa Fujii, Michalis Raptis, *Towards End-to-End Unified Scene Text Detection and
Layout Analysis*, CVPR 2022. [Official dataset](https://github.com/google-research-datasets/hiertext).
Publisher license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Publisher transcription strings and original vertices in the Engine 4.2 manifest/evaluation
artifacts retain these attribution/license terms; they are not relicensed as project code.

Individual Open Images/CVDF source images: source author, title, landing-page URL and
CC BY 2.0 license appear per observation in `engine42_hiertext_manifest.json`. Original
images/derived crops are stored locally outside Git and are not redistributed here.
Transformations are documented: resize to annotation dimensions, line-envelope crop,
then the explicitly named OCR preparation profile. Ground-truth strings are unchanged.

All museum-image browser/performance controls are separately authored software fixtures,
not independent data or real factual announcements. No font binaries are redistributed.
